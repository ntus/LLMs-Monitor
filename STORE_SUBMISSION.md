# Store submission checklist

`dist/LLMs-Token-Usage-Monitor-v1.4.0.zip` is the store submission package. Its manifest is localized as “LLMs トークン残量モニタ” in Japanese and “LLMs Token Usage Monitor” in English.

Developer-mode-free installation requires review and publication through Chrome Web Store and Microsoft Edge Add-ons. Before submission:

1. Register the owner developer accounts and enable two-step verification where required.
2. Host `PRIVACY.md` at a publicly accessible privacy-policy URL.
3. Upload the ZIP, store icon, screenshots, Japanese/English descriptions, and test instructions.
4. Declare that the three host permissions are used only to read the signed-in account's plan and usage information locally.
5. Declare the temporary in-memory use of ChatGPT's first-party access token and confirm that it is never stored or shared.
6. Submit for review, then replace the website package link with the approved Chrome Web Store and Edge Add-ons URLs.
