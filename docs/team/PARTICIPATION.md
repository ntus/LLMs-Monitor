# 参加ガイド / Participation boundaries

## 自分の契約・自分の認証 / Own plan and authentication

- 各参加者は、自分が利用を認められたAI・契約・端末で担当作業を行います。APIキー、Cookie、セッショントークン、パスワード、ブラウザープロファイルを他人や別AIへ渡しません。
- APIを使う場合も、キーは参加者の既存の安全なローカル設定に留めます。GitHub、Issue、PR、状態JSON、ai-bus、公開Webへ貼りません。追加料金のあるAPI実行は、目的・送信対象・上限費用を決めて別途了承を得ます。
- このMVPには、サブスクリプション残量を別のアカウントへ「移す」「合算する」「貸す」機能はありません。協力は、余力のある担当者へ**作業範囲を依頼すること**です。利用規約やアカウント共有制限を回避する分割は行いません。

Each participant uses an AI, plan and device they are authorized to use. Credentials remain with their owner. Paid API work requires a separate concrete data/cost agreement. This proposal delegates bounded work; it does not transfer, pool, lend, or bypass account quotas or provider terms.

## 公開してよい情報 / Information to share

共有するのは、再現用の合成データ、一般化した仕様、最小限のソース差分、テスト結果、レビューの指摘などです。顧客情報、会話全文、個人の残量履歴、請求先情報、秘密を除きます。既存の私有リポジトリの公開範囲を勝手に変えません。

Share synthetic reproduction data, generalized requirements, minimal source changes and test evidence. Exclude customer data, full conversations, personal quota history, billing identity and secrets. Preserve the existing audience of private repositories.

## 状態の申告 / Capacity reports

「余裕あり」「注意」「枯渇に近い」は自己申告です。24時間以内でも最新の公式値とは限りません。着手前に本人が実際の残量・権限・費用を確認し、無理なら断るか引き継ぎます。取得不能や欠損は「未確認」とし、0や回復と推測しません。

Self-reports remain self-reports. The assignee checks actual capacity, authorization and cost before starting. Missing data is unknown, never zero or recovered. No one must disclose an API key or account identity to participate.
