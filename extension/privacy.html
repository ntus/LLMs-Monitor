Privacy Policy

The extension reads plan names, usage limits, remaining percentages, reset times, and related credits from the official ChatGPT, Claude, Gemini, and Google One services already signed in within the same browser profile. Google One is queried only when Gemini does not expose the current Google AI membership name.

Authentication

For ChatGPT usage requests, an access token exposed to the signed-in official page is held only in memory during the request. It is never saved, logged, displayed, or sent to the developer or a third party. Passwords and prompt contents are never read.

Local data

Usage snapshots, up to 10,000 changed values per usage window, the selected Claude organization identifier, and display preferences are stored in chrome.storage.local. History survives sign-out, browser restart, and extension updates. The comparison baseline resets after signing in again. Uninstall the extension or clear its extension storage to delete the data.

Companion web page

When you connect the extension ID to https://llmsmonitor.ntus.info / https://llmsmonitor.ntusnog.chatgpt.site, the extension returns only the plan, usage, credit, history, and preference fields needed to render the monitor locally in that browser. The page does not upload those values to NT MicroSystems,Inc.

Sharing and automated actions

Data is not sold or shared for advertising, profiling, credit decisions, or unrelated purposes. The extension does not send prompts, buy credits, change subscriptions, or exercise reset entitlements. Any final action after following a usage link takes place on the provider's official site under the user's control.

Contact

NT MicroSystems,Inc.

Optional API balances

API credit connections are optional and disabled by default. A user click in the extension requests access to the selected official API billing host (OpenAI Platform, Claude Platform or Google AI Studio) and optional scripting. On billing routes only, the local reader extracts explicitly labelled currency balances. It stores amount, currency, acquisition status, an account-scope fingerprint and observation time under a separate local key. It does not read input fields, API keys, passwords or payment details, and does not send page text or account names. Keep the billing page open; the reader checks displayed values about once a minute. Disconnect removes the host permission. API balances remain separate from subscription limits and existing history.

プライバシーポリシー

本拡張機能は、同じブラウザープロファイルでログイン済みのChatGPT、Claude、Gemini、Google Oneの公式サービスから、契約プラン名、利用枠、残り割合、リセット日時、関連クレジットを取得します。Gemini側で現在のGoogle AI契約名を取得できない場合に限り、Google Oneを照会します。

認証情報

ChatGPTの使用量要求では、公式ページが現在のログインに提供するアクセストークンを要求中だけメモリー内で使用します。保存、ログ出力、表示、開発者や第三者への送信はしません。パスワードとプロンプト本文は読み取りません。

端末内に保存する情報

使用量スナップショット、利用枠ごとに最大10,000件の変化履歴、選択したClaude組織識別子、表示設定を chrome.storage.local に保存します。ログアウト、ブラウザー再起動、拡張機能の更新後も履歴は維持され、再ログイン後の比較基準だけをリセットします。削除するには拡張機能をアンインストールするか、拡張機能ストレージを消去してください。

コンパニオンWeb画面

拡張機能IDを https://llmsmonitor.ntus.info / https://llmsmonitor.ntusnog.chatgpt.site に接続した場合、表示に必要な契約、使用量、クレジット、履歴、設定だけを同じブラウザー内の画面へ返します。それらをNT MicroSystems,Inc.のサーバーへアップロードする処理はありません。

外部提供と自動操作

データを販売したり、広告、プロファイリング、信用判断、無関係な目的に共有したりしません。プロンプト送信、クレジット購入、契約変更、リセット権行使を自動実行しません。利用リンクの先での最終操作は利用者が公式サイトで行います。

任意のAPI残高連携

APIクレジット連携は任意で初期状態は無効です。拡張機能内のボタンを押したときだけ、選択した公式API請求ホスト（OpenAI Platform／Claude Platform／Google AI Studio）とscriptingの任意権限を要求します。請求パスで明示された通貨残高を読み取り、金額・通貨・取得状態・請求範囲の指紋・観測時刻のみを別のローカルキーへ保存します。入力欄、APIキー、パスワード、決済情報は読み取らず、ページ全文やアカウント名を送信しません。請求画面を開いておくと約1分ごとに表示値を確認します。解除時にホスト権限を削除します。API残高を月額プラン枠や既存履歴へ混入させません。
