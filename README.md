# Glance — AI残量モニター

## 1.1.0 の変更

- 残量が変化した利用枠に、変更直前の値と取得日時（秒まで・端末のタイムゾーン）を表示。同じ値の再取得では直近の変更履歴を保持します。
- 更新中は前回値を保持してゆっくり点滅。45秒を超えた場合は「更新待ち（前回値）」に切り替えます。端末でアニメーション抑制を指定している場合は薄色のみです。
- Claudeのクラウドセッションクレジット、プロジェクトセットアップクレジット、使用クレジットを下部に追加。取得可能な金額・残率・期限を表示。Web画面で金額を確認できない場合は「未取得」とします。
- 更新するには最新ZIPを展開し、既存の拡張機能フォルダのファイルを置き換えて、拡張機能管理画面の「再読み込み」を押してください。各AIサイトとモニターも再読み込みしてください。

OSに依存しない静的Webアプリと、Chrome / Edgeデスクトップ用Manifest V3拡張機能です。Safari、Firefox、モバイルブラウザへの対応は未検証です。

## 使い方

1. Webページの「拡張機能をダウンロード」でZIPを展開します。
2. Chromeの `chrome://extensions`（Edgeなら `edge://extensions`）でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選びます。
3. ツールバーのGlanceをクリックすると、拡張機能に内蔵したWebアプリが開きます。各サービスの「接続」を押します。
4. 公式使用量画面を専用タブで開きます。同じブラウザプロファイルでログイン済みなら、そのセッションが使われます。未ログインなら公式サイトで認証してください。Glanceにパスワードを入力する画面はありません。
5. 使用量タブを開いたままにしてください。毎分再読み込みし、表示内容の変化は約2秒で検出します。バックグラウンドタブの停止やブラウザのスリープ、公式画面の遅延によって更新が遅れる場合があります。
6. 各AIサイトの既存タブは拡張機能導入後に再読み込みしてください。右下のパネルが表示されます。透明度と四隅の位置はモニターから設定できます。

ホストされたWebアプリは、拡張機能の詳細画面にある32文字のIDを入力すると接続できます。拡張機能に内蔵したモニターはID入力不要・ネット接続なしでも起動できます。取得には各サービスへの通信が必要です。

## 表示と制約

- Claude: 現在のセッション・週間の使用済み率から残量を算出。製品別内訳や追加クレジットは混ぜません。
- Gemini: 公式使用量ページの現在・週間の使用率から残量を算出。
- ChatGPT: 現時点で確認した公式使用量ページは通常Chatを含みません。表示できるのは **Work / Codex等の共通利用枠** です。「通常のChat：取得不可」と明記します。Chatの正確な残量は未実装・取得未確認です。
- 数値がない場合は「—」。更新中・取得失敗時は前回取得値を保持し、ログアウト時は数値を消去。125秒以上経過すると「更新待ち」を表示します。
- 常駐パネルは対象3サイトのページ内に表示されます。ほかのアプリの上への表示には対応ブラウザのDocument Picture-in-Picture小窓を使います。OS全体の透明オーバーレイではありません。
- 複数アカウントの合算はしません。各サービスの専用タブに表示されるアカウントが対象です。アカウント切り替え後は公式使用量画面を開いて更新してください。
- 公式DOM構造を読むため、サービス側の変更で修正が必要になることがあります。

## データ・権限

Cookie・パスワード・APIキーは読み取りません。送信ボタンや購入操作も自動実行しません。DOMから取り出すのは利用枠名・残率・リセット表示だけです。使用量は拡張機能のsessionストレージ、表示設定はlocalストレージに保存します。サーバーへ使用量をアップロードする処理はありません。Web版への共有先はmanifestの指定オリジンだけです。

拡張機能に対する3サイトの閲覧権限はインストール時に必要です。専用の使用量タブだけを自動更新します。ブラウザを再起動した場合は再接続してください。

## 開発

- `python3 -m http.server 4173 --directory dist` でローカルWeb版を起動。
- `node --test tests/*.test.cjs` で残量パーサーを検証。
- `python3 build.py` で共通ファイルを拡張機能に複製し、配布ZIPを更新。
- `dist/` が静的Web配布物。`extension/` が読み込み可能な拡張機能。

2026-09-27に公式画面のメーター構造を確認しました。拡張機能の実アカウントでの通し動作は、インストール後に検証する必要があります。
